## 📊 技术栈概览

### 后端服务
- **Node.js** 18+ (TypeScript 5.6)
- **Go** 1.24.9 (uTLS 1.8.1)
- **Protocol Buffers** (数据序列化)
- **FastQ** (无锁队列)
- **WebSocket** (实时通信)

### 部署工具
- **PM2** (进程管理)
- **Caddy** 2.x (反向代理)
- **Git** (版本控制)

### 核心技术
- ✅ uTLS TLS 指纹模拟（完美模拟 Chrome）
- ✅ IPv6 地址池轮询（避免单点失败）
- ✅ DNS IP 池优化（减少 DNS 解析延迟）
- ✅ HTTP/2 连接复用（提升性能）
- ✅ 熔断器机制（自动故障隔离）
- ✅ Session 管理（自动 Cookie 刷新）

## 📈 性能指标

| 指标 | 数值 | 说明 |
|------|------|------|
| **QPS** | 10-15 req/s | 单节点每秒请求数 |
| **成功率** | >99% | 请求成功率 |
| **平均响应时间** | 150-300ms | 使用 IP 池优化后 |
| **P95 响应时间** | <500ms | 95% 请求响应时间 |
| **并发处理** | 20 并发 | 同时处理的请求数 |
| **内存使用** | ~85MB | Node.js + Go 代理 |

详见 [性能分析文档](./PERFORMANCE.md)
